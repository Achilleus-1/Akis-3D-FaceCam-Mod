# Security

Security fixes target the current `main` branch. This is beta software; review
the documented verification limits before enabling webcam sharing.

Report suspected privacy or credential exposure through
[GitHub private vulnerability reporting](https://github.com/Achilleus-1/Akis-3D-FaceCam-Mod/security/advisories/new).
Include the affected version, impact, and reproduction steps. Do not post face
images, recordings, personal server addresses, credentials, or private logs in
public issues. If private reporting is unavailable, contact the maintainer through
the [Achilleus profile](https://github.com/Achilleus-1) before disclosing details.

Capture and sharing start off. Face inference runs locally. Sharing sends face
imagery to the connected Minecraft server and eligible nearby modded clients;
they can inspect or record it. Only share on servers you trust. The mod captures
no audio and sends no data to cloud inference services.
